# TP : Bank Service

## Présentation

Ce projet est un travail pratique (TP) réalisé pour découvrir le développement d’une API REST avec Java et Spring Boot. Il permet de gérer des comptes bancaires : consulter, créer, modifier et supprimer des comptes, ainsi que rechercher des comptes par type.

## Technologies

- Java 21
- Spring Boot 4.1.1
- Spring Web MVC
- Spring Data JPA et Spring Data REST
- Base de données H2 en mémoire
- Swagger UI et OpenAPI
- Maven et Lombok
